# 2026-10-26 Brave 實測紀錄

原始版本：`3.1.0`（`c6b0189`）。修正版本：`3.1.1`。

## 發現與修正

1. 官方詳情回傳「商家选择无需物流发货，暂无物流信息」的服務類訂單，被當成物流失敗。現在驗證詳情主訂單號、確認沒有既有包裹後，記為 `not_required`，保留官方說明。
2. 已關閉交易的物流 API 回傳 `NoPackageInfo`，詳情亦無包裹，被列為失敗。SDK 會直接 reject 這類業務回應，因此必須在共用 `apiError` 轉換層保留 `NO_PACKAGE_INFO`，不能只在解析器處理。只有交易已關閉、兩個官方來源均無紀錄、也沒有既有包裹時，才記為 `no_package`。進行中或交易成功的訂單仍會回報待核對。
3. 多包裹查至後續包裹時遇到驗證／停止，當筆新取得的部分包裹沒有先落盤。現在先保存進度，再保留本頁斷點並中止。
4. 先前使用詳情後備造成的「軌跡待補查」錯誤，可能在後續查詢成功後殘留。現在依本次查詢結果清除。
5. 中止原因原本只在頁面記憶體中，重新整理後只顯示斷點。現在保存 `job.lastError`，並在重新整理後顯示。原先為何停在第 2 頁，因舊版沒有保存原因，無法追溯斷定。
